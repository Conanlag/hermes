# TC-035: Una operación aceptada sobrevive al corte del cliente

**Requisitos cubiertos:** RF-28
**Métodos de verificación:** Prueba
**Nivel de prueba:** Funcional y robustez

#### 1. Fase de Diseño (Planificación)
* **Objetivo:** Verificar que un `submit` ya aceptado y persistido conserva su estado íntegro cuando el cliente corta la conexión antes de leer la respuesta, y que la interrupción queda documentada como `ACEPTADA` con el `job_id` afectado.
* **Precondiciones:** Linux o WSL con Bash y Python 3; Hermes compilado; `HOME` temporal aislado; puerto `45830` libre.
* **Entorno y configuración:** `config.json` propio de la prueba con `puerto: 45830` y `redes_permitidas: ["127.0.0.0/8"]`; `network.json` que autoriza a `PC-B` desde `127.0.0.1` para `submit`, `query`, `list` y `cancel`; servidor lanzado por el script.
* **Datos de entrada:** Un `submit` de `true` con `request_id: tc035-corte`, enviado completo y seguido de un `RST` inmediato (`SO_LINGER` con plazo 0).
* **Pasos reproducibles:**
  1. Compilar con `make -C src/hermes hermes`.
  2. Ejecutar `bash verif/scripts/TC-035.sh`.
  3. Revisar el código de salida y `verif/results/results_TC-035.md`.
* **Resultado esperado:** `jobs.json` conserva el Job con programa y estado válido y lo lleva a estado terminal; el evento `Solicitud interrumpida` declara `resultado: ACEPTADA`, la operación `submit`, el `request_id` enviado y un `job_id` presente en `jobs.json`; no aparece ningún evento `Cliente desconectado` para esa solicitud; el servicio responde un `ping` posterior.

#### 2. Fase de Ejecución (Resultados empíricos)
* **Resultado observado:** Ejecución del 2026-11-19 en WSL Ubuntu con código `0`. El Job quedó persistido y alcanzó estado terminal; la bitácora registró `Solicitud interrumpida` con `resultado: ACEPTADA`, `motivo: ERROR_SOCKET`, `operacion: submit`, `request_id: tc035-corte`, `job_id: 1` y `bytes_recibidos: 117`; no hubo entradas `Cliente desconectado`; el `ping` posterior respondió correctamente.
* **Artefactos de evidencia:** `verif/scripts/TC-035.sh`; `verif/results/results_TC-035.md`.
