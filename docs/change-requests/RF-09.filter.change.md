Claro. En este caso el **Change Request** solo debe documentar el cambio solicitado: agregar `programa` como nuevo parámetro del comando `filter`, sin entrar todavía en la implementación.

# Cambio en el filtro de procesos

## 1. Descripción del cambio

Se propone agregar **`programa`** como un nuevo parámetro disponible para el comando `hermes filter`.

Actualmente el filtro permite consultar procesos mediante su **ID** y **estado**. Con este cambio se podrá realizar una consulta utilizando el nombre del programa declarado al crear el proceso mediante:

```bash
hermes job <programa>
```

El nuevo filtro permitirá agrupar y consultar los procesos que tengan el mismo nombre de programa.

## 2. Cambio solicitado

Agregar `programa` como nuevo tipo de filtro:

```bash
hermes filter programa <nombre_programa>
```

Por ejemplo:

```bash
hermes filter programa ls
```

El valor recibido deberá corresponder al nombre del programa utilizado al crear el Job.

## 3. Comportamiento esperado

Cuando se utilice el filtro `programa`, Hermes deberá buscar los procesos cuyo nombre de programa coincida con el parámetro proporcionado.

Esto permitirá consultar un conjunto de procesos que fueron creados utilizando el mismo programa.

Por ejemplo, si existen varios Jobs:

```text
Job 1 → ls
Job 2 → ls
Job 3 → firefox
Job 4 → ls
```

al ejecutar:

```bash
hermes filter programa ls
```

se deberán consultar los procesos asociados al programa `ls`.

## 4. Comando

La sintaxis del comando será:

```bash
hermes filter programa <nombre_programa>
```

Donde:

* `programa` identifica el tipo de filtro.
* `<nombre_programa>` corresponde al programa declarado en `hermes job`.

## 5. Justificación

Agregar este parámetro permite realizar consultas tomando como referencia el programa utilizado para crear los Jobs.

Un mismo programa puede estar asociado con múltiples procesos, por lo que este filtro permitirá consultar el conjunto de Jobs que comparten el mismo nombre de programa.

## 6. Alcance del cambio

El cambio consiste únicamente en agregar **`programa` como parámetro de filtrado** al comando `hermes filter`.

Los filtros existentes por `id` y `status` deberán mantenerse sin modificaciones.

Los demás comportamientos relacionados con la ejecución, administración o cambio de estado de los procesos quedan fuera del alcance de este Change Request.
