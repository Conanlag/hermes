# TC-018: Rendimiento de consulta y conservación de 500 Jobs

**Requisitos cubiertos:** RNF-05 y RNF-06  
**Nivel de prueba:** Integración

## Objetivo

Medir la consulta de estado con 100 registros persistidos y comprobar que Hermes conserva metadatos y resultados de 500 Jobs creados por CLI.

## Precondiciones

- Linux con Bash, Perl `JSON::PP` y Hermes compilado.
- Usa `verif/json_test/TC-18/jobs.json` como fixture y lo copia a un `HOME` temporal; el original no se modifica.
- No se modifica el historial de Jobs del usuario.

## Ejecución

Desde `src/hermes`:

```bash
make -C src/hermes
bash verif/scripts/TC-018.sh
```

El script comprueba que el fixture contiene al menos 500 Jobs y que todos los registros tienen IDs únicos y metadatos válidos. Luego mide con el comando `time` de Bash `hermes filter programa echo`, verifica que devuelva al menos 100 Jobs y exige una duración menor a 1 segundo. No crea nuevos Jobs.

Para medir el tiempo total de ejecución del caso además del umbral individual:

```bash
bash -c 'time bash verif/scripts/TC-018.sh'
```

La salida aparece en la terminal y se agrega a `verif/results/results_TC-018.md`, con la fecha y hora de cada ejecución. El directorio temporal se elimina al terminar.

## Resultado esperado

El script termina con código `0` y muestra valores como:

```text
RNF-05: time hermes filter programa echo con 519 registros = 0.058s
RNF-06: 519 Jobs del fixture conservan IDs, metadatos y resultados.
PASS: RNF-05 y RNF-06
```

Los tiempos cambian según la máquina; la consulta debe ser inferior a `1s`.
