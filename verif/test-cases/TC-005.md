### TC-005: Solicitar cancelación de proceso en ejecución
**Requisitos cubiertos:** RF-10
**Nivel de prueba:** Sistema - Parcial Fase 1

#### 1. Fase de Diseño (Planificación)
* **Objetivo:** Validar la cancelación de un trabajo en ejecución (alcance parcial Fase 1: solo `RUNNING`, sin rama `QUEUED`): solicitarla, confirmar el `SIGTERM` al proceso real y reflejar `CANCELED` con su código sin afectar a otros trabajos.
* **Precondiciones:** Repositorio clonado limpio; `src/hermes` compilado con `make clean && make` sin errores; `data/jobs.json` respaldado; ningún `sleep 30` residual corriendo de pruebas previas.
* **Entorno y configuración:** Linux (WSL), compilador GCC (g++, `-Wall -Wextra -std=c++17 -Iinclude`), entorno controlado, clon limpio, límite de concurrencia definido en config.json.
* **Datos de entrada:** `./hermes job sleep 30` (ID `R` en `RUNNING`), `./hermes job echo testigo` (ID `T` de control), `./hermes cancel R`, `./hermes filter id R`, `./hermes filter id T`.
* **Pasos reproducibles:**
  1. Compilar: `cd src/hermes && make clean && make`.
  2. Crear objetivo y testigo: `./hermes job sleep 30` (anotar `R`) y `./hermes job echo testigo` (anotar `T`).
  3. Confirmar ejecución: `./hermes filter id R` y comprobar `Estado: RUNNING` con `PID` válido.
  4. Solicitar cancelación: `./hermes cancel R` y comprobar mensaje `Cancelación solicitada para el Job: R` con código `0`.
  5. Reflejar resultado: esperar 2 s; `./hermes filter id R` y comprobar `Estado: CANCELED` con `Codigo de salida: -15` (`-SIGTERM`).
  6. Aislamiento: `./hermes filter id T` y comprobar que el testigo conserva su estado (`SUCCEEDED`) sin alteraciones.
  7. Rechazos con causa: `./hermes cancel 999999` (`No existe el Job ID`, código `1`) y `./hermes cancel T` si ya terminó (`no se puede cancelar (estado: SUCCEEDED)`, código `1`).
* **Resultado esperado:** Paso 4 acepta con código `0`; paso 5 muestra `CANCELED/-15`; paso 6 intacto; paso 7 rechaza con causa y código `1`. Fuera de alcance Fase 1: cancelación directa de `QUEUED` y reintentos/`SIGKILL`.
