# TC-024: Máximo configurable de trabajos simultáneos

**Requisitos cubiertos:** RF-05, RNF-04, RNF-07
**Nivel de prueba:** Integración

## Objetivo

Verificar que `hermes configmax <N>` actualiza `trabajos_maximos`, conserva otras claves de `config.json`, rechaza valores fuera del rango `1–64` y usa el valor configurado para limitar la concurrencia del scheduler.

## Precondiciones

- Linux con Bash, Perl `JSON::PP` y Hermes compilado.
- La prueba usa un `HOME` temporal y no modifica los datos del usuario.

## Ejecución

Desde la raíz del repositorio:

```bash
make -C src/hermes
bash verif/scripts/TC-024.sh
```

La prueba actualiza la configuración mediante `hermes configmax <N>`, verifica que los datos ajenos a esa clave se conserven y comprueba los rechazos de valores inválidos. Finalmente lanza tres trabajos largos con el máximo configurado en `3`, espera a observar los tres como `RUNNING` y confirma que se rechaza un cuarto. El scheduler lee el valor cuando inicia; si ya estaba activo, `configmax` no lo reinicia. Para aplicar el nuevo número de workers se requiere `hermes clean scheduler`, que interrumpe los trabajos que estén ejecutándose.

## Resultado esperado

El script termina con código `0` y muestra:

```text
PASS: configmax persistió el valor, conservó otras claves, rechazó valores inválidos y el scheduler ejecutó tres Jobs simultáneos sin superar el límite.
```
