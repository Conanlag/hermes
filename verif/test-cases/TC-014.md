### TC-014: Construcción reproducible desde clon limpio
**Requisitos cubiertos:** RNF-01, RNF-02, RNF-03
**Nivel de prueba:** Aceptación - Fase 1

#### 1. Fase de Diseño (Planificación)
* **Objetivo:** Validar que Hermes compila y se ejecuta en la distribución Linux declarada por el equipo, que la construcción es reproducible desde un clon limpio solo con instrucciones y dependencias documentadas, y que la operación normal no requiere privilegios de root.
* **Precondiciones:** Acceso a la URL del repositorio y a la lista de dependencias documentadas (`g++` con C++17, `make`, `python3` solo para pruebas manuales); usuario normal sin `sudo` para la prueba RNF-03; conectividad para clonar.
* **Entorno y configuración:** Linux declarado por el equipo (WSL en esta fase), compilador GCC, entorno controlado, clon limpio, límite de concurrencia definido en config.json.
* **Datos de entrada:** Clon fresco en directorio temporal; `make clean && make` en `src/hermes`; comandos de humo `./hermes --version`, `./hermes job echo hola`, `./hermes filter id <N>`; verificación `whoami` / ausencia de `sudo`.
* **Pasos reproducibles:**
  1. Clonar limpio: `git clone <URL> hermes-limpio && cd hermes-limpio/ppl/src/hermes` (no reutilizar el clon de desarrollo).
  2. Verificar dependencias documentadas: `g++ --version`, `make --version`; contrastar contra la documentación (RNF-02 exige que baste con lo documentado).
  3. Construir: `make clean && make` y comprobar salida sin errores ni advertencias bloqueantes y binario `./hermes` generado.
  4. Confirmar usuario normal: `whoami` (distinto de `root`) y `id -u` (distinto de `0`); no usar `sudo` en ningún paso posterior.
  5. Humo funcional: `./hermes --version` (código `0`), `./hermes job echo hola` (imprime `job ID`, código `0`), `./hermes filter id <N>` (muestra el trabajo, código `0`).
  6. Confirmar instalación opcional sin root: `make install` instala en `~/.local/bin` (ruta de usuario) sin requerir privilegios.
* **Resultado esperado:** Pasos 2–3 construyen desde cero solo con lo documentado; pasos 4–6 operan íntegramente como usuario normal con códigos `0`; el binario del clon limpio se comporta igual que el de desarrollo (RNF-01 + RNF-02 + RNF-03 satisfechos en Fase 1).
