# TC-017: Idempotencia de solicitudes de creacion de Jobs

**Requisito cubierto:** RF-27  
**Nivel de prueba:** Integracion

## Objetivo

Verificar que los reintentos con la misma clave no creen Jobs duplicados y que un uso incompatible de la clave no cambie el registro existente.

## Precondiciones

- Linux con Python 3 y Hermes compilado.
- La prueba configura un `HOME` temporal y no modifica los datos reales del usuario.

## Pasos

Ejecutar desde `src/hermes`:

```bash
make clean all
bash ./tests/test_rf27.sh
```

El script lanza ocho solicitudes concurrentes con la misma clave y contenido, comprueba que todas devuelven el mismo ID y que hay un unico registro para la clave en `jobs.json`. Luego reenvia la clave con argumentos diferentes y verifica que Hermes responde con error sin crear otro Job. Tambien repite una solicitud cuyo Job ya termino y confirma que se conservan su ID y resultado. Finalmente crea un Job sin clave para confirmar que las solicitudes no identificadas siguen siendo independientes.

## Resultado esperado

El comando termina con codigo `0` y muestra:

```text
PASS: claves repetidas son atomicas, reutilizan el Job y rechazan payloads distintos.
```
