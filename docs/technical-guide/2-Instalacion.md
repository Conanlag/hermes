# Instalacion de proyecto 

## Correr el proyecto

desde la ruta relativa  `ppl/src/hermes` ejecutar los siguientes comandos

- para compilar:
```
make
```
- para instalar el comando hermes
```
make install
```
-  para ejecutar los comandos 
```
hermes
```
- para borrar el archivo .o
```
make clean
```
