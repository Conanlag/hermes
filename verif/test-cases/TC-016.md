# TC-016: Persistencia y recuperación de Jobs tras reinicio

**Requisito cubierto:** RF-13 (RF-12 actualizado)  
**Nivel de prueba:** Integración

## Objetivo

Comprobar que Hermes conserva metadatos y resultados de un Job terminado después de reiniciar el scheduler, y que los Jobs que quedaron en `RUNNING` sin identidad verificable se recuperan como `INTERRUPTED` sin perder sus metadatos.

## Precondiciones

- Linux con Bash, Perl `JSON::PP` y Hermes compilado.
- La prueba usa un `HOME` temporal y no modifica los datos del usuario.
- El directorio de datos de Hermes debe poder crearse en el `HOME` temporal.

## Ejecución

Desde la raíz del repositorio:

```bash
make -C src/hermes
bash verif/scripts/TC-016.sh
```

El script crea y finaliza un Job mediante Hermes, detiene el scheduler de prueba, agrega un registro `RUNNING` al historial persistido y vuelve a iniciar Hermes. Comprueba que el Job finalizado conserva su ID, programa, argumentos, tiempos y código de salida; también verifica que el Job interrumpido conserve sus metadatos, quede en `INTERRUPTED` con `motivo=sin_identidad`, reciba código de salida `-1`, mensaje de interrupción y tiempo de terminación, y que no se afirme la terminación de un proceso que no se pudo verificar.

El resultado de cada ejecución se agrega a `verif/results/results_TC-016.md`. El script elimina el directorio temporal al finalizar.

## Resultado esperado

El script termina con código `0` y muestra:

```text
PASS: los Jobs terminados conservan metadatos y resultados; los RUNNING no verificables se recuperan como INTERRUPTED.
```
