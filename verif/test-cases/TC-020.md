# TC-020: Liberación de recursos después de estrés

**Requisito cubierto:** RNF-33 (cobertura parcial)  
**Nivel de prueba:** Integración / estrés

## Objetivo

Comprobar que, después de ejecutar múltiples Jobs, Hermes recupera el uso de memoria del scheduler dentro de una tolerancia definida, no deja procesos hijos activos, cierra sus descriptores temporales y elimina los archivos temporales de persistencia.

## Precondiciones

- Linux con Bash, Perl `JSON::PP` y Hermes compilado.
- Acceso a `/proc` para inspeccionar RSS, descriptores y procesos.
- La prueba usa un `HOME` temporal; no modifica los datos del usuario.

## Ejecución

Desde la raíz del repositorio:

```bash
make -C src/hermes
bash verif/scripts/TC-020.sh
```

El script ejecuta 100 Jobs `true`, en lotes concurrentes de hasta 10. Después de esperar a que todos terminen y dejar 2 segundos de reposo, compara el RSS del scheduler con la línea base (se permite un incremento máximo de 8192 KiB), compara la cantidad de descriptores y sockets con la línea base, verifica que no haya procesos hijos ni archivos `jobs.json.tmp.*` y detiene el scheduler para confirmar que sus descriptores se liberan.

Se puede cambiar la cantidad de Jobs, siempre que sea al menos 10:

```bash
bash verif/scripts/TC-020.sh 500
```

Cada ejecución agrega su salida a `verif/results/results_TC-020.md`; el directorio temporal se elimina al finalizar.

## Límite de cobertura

El código actual no crea ni administra sockets. Por tanto, el caso comprueba que el scheduler no deja descriptores de socket abiertos, pero no puede demostrar la liberación de sockets utilizados durante el estrés. RNF-33 queda parcialmente cubierto hasta que Hermes implemente una ruta funcional que use sockets y se pueda someter a estrés.

## Resultado esperado

Para los recursos implementados, el script termina con código `0`, muestra `PASS parcial` y confirma que la memoria queda dentro de la tolerancia, no hay procesos hijos ni archivos temporales y el scheduler libera sus descriptores al detenerse. La cobertura completa del requisito requiere una prueba de ciclo de vida de sockets.
