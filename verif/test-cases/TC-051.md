# TC-051: Veinte solicitudes secuenciales sobre una conexión

**Requisitos cubiertos:** RNF-24
**Métodos de verificación:** Prueba
**Nivel de prueba:** Funcional y robustez

#### 1. Fase de Diseño (Planificación)
* **Objetivo:** Verificar que una conexión admite un ciclo largo de solicitud-respuesta sin cerrarse y que el cierre posterior del cliente es limpio, sin sobre de error ni registros anómalos.
* **Precondiciones:** Linux o WSL con Bash y Python 3; Hermes compilado; `HOME` temporal aislado; puerto `45857` libre.
* **Entorno y configuración:** `config.json` propio con `puerto: 45857`; `network.json` que autoriza a `PC-B` desde `127.0.0.1`; servidor lanzado por el script.
* **Datos de entrada:** Veinte `ping` (`tc051-01`…`tc051-20`) sobre la misma conexión, leyendo la respuesta antes de enviar el siguiente. Después, un `ping` adicional seguido de `shutdown(SHUT_WR)`.
* **Pasos reproducibles:**
  1. Compilar con `make -C src/hermes hermes`.
  2. Ejecutar `bash verif/scripts/TC-051.sh`.
  3. Revisar el código de salida, `verif/results/results_TC-051.md` y `events.jsonl` del `HOME` temporal.
* **Resultado esperado:** Las veinte respuestas tienen `ok: true` y el `request_id` esperado. Tras el FIN no llega ningún sobre adicional. `events.jsonl` no contiene `Solicitud interrumpida` ni `Cliente desconectado`.

#### 2. Fase de Ejecución (Resultados empíricos)
* **Resultado observado:** Ejecución del 2026-11-22 en WSL Ubuntu con código `0`. Las `20` solicitudes se atendieron en `0.01 s`; el FIN posterior produjo cierre limpio sin datos adicionales; la bitácora registró `0` solicitudes interrumpidas y `0` desconexiones anómalas.
* **Artefactos de evidencia:** `verif/scripts/TC-051.sh`; `verif/results/results_TC-051.md`.
