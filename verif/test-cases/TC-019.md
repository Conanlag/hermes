# TC-019: Cancelaciones concurrentes coherentes

**Requisito cubierto:** RF-26  
**Nivel de prueba:** Integración

## Objetivo

Ejecutar dos solicitudes de cancelación simultáneas sobre cada Job y verificar que el resultado persistido sea `CANCELED` y que `jobs.json` siga siendo JSON válido.

## Precondiciones

- Linux con Bash, Perl `JSON::PP` y Hermes compilado.
- El test configura un `HOME` temporal y no modifica el historial real del usuario.

## Ejecución

Desde la raíz del repositorio:

```bash
make -C src/hermes
bash verif/scripts/TC-019.sh
```

El test acepta el número de iteraciones como primer argumento (por omisión, 10):

```bash
bash verif/scripts/TC-019.sh 100
```

Cada ejecución se muestra en la terminal y se agrega con fecha y hora a `verif/results/results_TC-019.md`.

## Resultado esperado

Todas las iteraciones terminan en `CANCELED`, cada comprobación encuentra JSON válido y el comando retorna código `0`.
