# Casos de prueba

Las referencias a `data/jobs.json` en los casos de prueba apuntan al archivo persistente `$HOME/.local/share/hermes/data/jobs.json`: dentro del repositorio, `src/hermes/data` es un enlace simbólico al directorio de datos. Este directorio también contiene `config.json`, `jobs.lock` y `scheduler.lock`. `config.json` controla el máximo de workers y la capacidad total de admisión mediante `trabajos_maximos` (predeterminado 5, rango 1–64). El límite de admisión se lee en cada invocación; para aplicar un cambio de concurrencia a un daemon activo, se puede detener con `hermes clean scheduler` y luego ejecutar un comando que inicie el scheduler.

Los casos [TC-016](./TC-016.md) (RF-12), [TC-017](./TC-017.md) (RF-27), [TC-018](./TC-018.md) (RNF-05 y RNF-06), [TC-019](./TC-019.md) (RF-26), [TC-020](./TC-020.md) (RNF-33, cobertura parcial) y [TC-021](./TC-021.md) (RNF-27) se ejecutan desde `verif/scripts/`. Sus resultados se guardan en `verif/results/results_TC-016.md`, `results_TC-017.md`, `results_TC-018.md`, `results_TC-019.md`, `results_TC-020.md` y `results_TC-021.md`, respectivamente.
